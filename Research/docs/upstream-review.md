# Original implementation review

Inspected the requested five modules from the cloned ArCo repository at commit `93ca6fae1acb4cbde9f4f8494fb8ee0029f205fe` before adapting them.

- `agrimatnet/model_quantile.py`: separate linear history/future projections into equal d_model, two TransformerEncoder stacks, pre-norm batch-first ReLU layers, masked history mean, gather of requested future positions, concatenated historical summary and future embedding, dropout/linear/ReLU quantile head. Masks mean “ignore.” The pinball objective averages across valid targets and quantiles. These structures and objective are retained, with a singleton date-only future token and no Hugging Face dependency.
- `agrimatnet/layers.py`: sinusoidal `torch.arange(max_len)` table sliced by sequence length. It cannot distinguish actual acquisition gaps. The adaptation evaluates the same frequency family at real elapsed day offsets from the first retained historical acquisition, for both historical and target positions. Calendar sine/cosine gives time-of-year context independent of the relative origin.
- `agrimatnet/train_quantile_ablation.py`: variable-length padding, masks, quantile loss, Adam, median error monitoring, and save/checkpoint conventions are useful. Its `random_split` acts on examples, so it is replaced with fixed geographic strips. The original best checkpoint uses validation loss; the adaptation selects validation RMSE and adds early stopping. Satellite/weather ablation flags and optional lead-weighted losses are unnecessary for the initial fair comparison.
- `dataset_builder/torch_dataset.py`: loads all npz object sequences eagerly, supports scaler and optional engineered weather features, and returns history/future masks and timestamps. The source cache contract depends on satellite steps and covariates. The UAV implementation replaces it with a dense disk-backed aligned raster array, sampled coordinate/date indices, strict same-season history selection, and actual-day sequence construction. No future measured value enters either input stream. The original target discretization boundaries differ from this project's requested crop-health thresholds and are replaced for reporting.
- `dataset_builder/scaler.py`: NaN-aware min/max or standardization plus optional separate target transforms. The generic implementation could be reused if scaling were needed, but native NDVI requires no fitted target scaling. The new baseline StandardScaler fits training features only. Additional historical spectral rasters must already have comparable physical scaling; there is no global all-partition scaler.

Preprocessing is separate from statistical fitting: alignment never learns temporal values, masks are not interpolated, and fit-time decisions use training/validation partitions only. Target validity is used only to select supervision and score known vegetation; inference eligibility depends exclusively on historical observations and an optional independently defined mask.

Original source and MIT license are retained in the clone; reused model structure also carries attribution and the license copy in `src/uav_ndvi/licenses/AgriMatNet-LICENSE`.
